
架localhost站
於elasticsearch.yml下方增加下面兩個設定
xpack.security.enrollment.enabled: true
xpack.security.enabled: true

elasticsearch-8.5.2\bin\elasticsearch.bat
elasticsearch-8.5.2\bin\elasticsearch-service install
elasticsearch-8.5.2\bin\elasticsearch-service start





重設elastic密碼及取得密碼
elasticsearch-reset-password -u elastic
取得新密碼後請以環境變數 TCP_ELASTIC_PASSWORD 或部署平台 secret 注入，不要寫入版本庫。


確認elastic已架
http://localhost:9200

架設kibana
kibana-8.5.2\bin\kibana.bat

功能入口頁面
http://localhost:5601/app/integrations/browse



elasticsearch-create-enrollment-token.bat --scope kibana
<請於部署時即時產生 enrollment token；不要將 token 寫入 repository>


取得kibana認證code
\kibana-8.5.2-windows-x86_64\kibana-8.5.2\bin\kibana-verification-code.bat


使用curl新增資料
curl -H "Content-Type: application/json" -XPOST "http://localhost:9200/indexname/typename/optionalUniqueId" -d "{ \"field\" : \"value\"}"

curl -XPOST http://localhost:9200/sptest -H "Content-Type: application/json" -d @data.json --insecure
