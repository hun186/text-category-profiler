# TW AI Technology Stock Trend Training Package

## Recommended taxonomy label

`TW AI Technology Stock Trend`

## Placement

Primary path:

`Informative → Geographic Areas → Asia Affairs → Asia-Pacific Affairs → East Asia Affairs → TW Affairs → TW Economics → TW Finance → TW Stock Market → TW Technology Stocks → TW AI Technology Stock Trend`

Parallel financial path already present in the taxonomy:

`Informative → International Economics → International Finance → International Financial Indicators → International Stock Market → TW Stock Market`

Additional parent context:

`TW Economics → TW Industrial Development → TW Company Development → TW Technology Company Development → TW Technology Stocks`

## Contents

- `新增邊_TW_AI_Technology_Stock_Trend.csv`: 12 new primary and cross-link edges, in the original five-column CSV format.
- `TW_AI_Technology_Stock_Trend_子圖.md`: Mermaid subgraph, placement rationale, edge table, label definitions and data policy.
- `TW_AI_Technology_Stock_Trend_子圖.png`: styled upstream/downstream subgraph.
- Four `#T#[...]` directories, each containing 100 Chinese and 100 English `.txt` records.
- `training_data_manifest.csv`: per-file source-index metadata and character counts.
- `quota_report.csv`: quota and length verification.

## Important data limitation

The package does **not** reproduce full copyrighted news or think-tank texts. It uses identified public sources for a small seed set and public news-search index URLs for the remaining records, together with newly written classification summaries. Every file clearly states this boundary. Human review is required before production training, especially for URL validity, source quality, date, language and label precision.

## Quota result

Each fine-grained label contains 100 Chinese and 100 English direct source-index samples. No parent-level gap filler was needed. Each label-language set exceeds 100,000 characters; see `quota_report.csv` for exact totals.
